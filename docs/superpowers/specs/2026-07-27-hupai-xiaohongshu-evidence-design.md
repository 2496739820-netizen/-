## 采用方案

采用“混合证据”而不是纯截图墙或纯编辑式作品卡。

### 原因

- 纯截图墙真实性强，但小红书界面信息密集，会破坏当前网站的高级感。
- 纯编辑式作品卡视觉统一，但招聘方无法立刻确认数据来源。
- 混合方案用小面积原始平台证据建立可信度，再用网站自己的视觉语言解释作品价值，兼顾可信度与审美。

## 页面结构

新增内容放在虎派经历标题与现有三个文字案例模块之间，不调整页面其他部分顺序。

### 1. 账号证据条

使用一条横向、低高度的信息区展示：

- 虎派眼镜小红书账号名称；
- 3604 粉丝；
- 1.7 万获赞与收藏；
- “2024.05 至今负责拍摄与运营”；
- “数据截取于 2026-07-27”说明；
- 跳转公开主页的链接。

账号证据条只提供事实，不使用夸张宣传语，不做新的大号标题。

### 2. 三张代表作品卡

桌面端采用“一张主案例 + 两张次案例”的不对称编辑式网格：

- 主案例为林德伯格全系列干货，占更大面积；
- 次案例为眼镜宇宙品牌策划和 999.9 运动眼镜短视频；
- 手机端改为单列，主次顺序不变。

每张卡包含：

1. 本地保存的作品封面或原始页面裁切图；
2. 内容类型标签；
3. 笔记标题；
4. 一句能力说明；
5. 公开互动数据；
6. 原始小红书笔记链接；
7. 数据截取日期的可访问说明。

### 3. 原始平台证据

- 每张作品卡使用作品封面作为主体。
- 主案例额外保留一张经过裁切的原始笔记详情截图，截图中只保留标题、账号和点赞／收藏／评论／分享区域。
- 不展示浏览器工具栏、侧栏通知数量、登录用户头像和无关评论内容。
- 点击作品卡时进入原始小红书笔记，不在网站内模拟小红书界面。

### 4. 与现有案例模块衔接

作品证据区之后保留当前三个文字案例：

1. 产品卖点、用户需求与平台趋势驱动的内容；
2. 员工账号矩阵与自然获客；
3. 平台投流、复盘与到店转化闭环。

新增一行衔接文案，说明上方是“看得见的内容结果”，下方是“可复用的运营方法”，避免视觉证据与方法论割裂。

## 视觉方向

- 延续现有暖象牙白背景、深墨色文字、黄铜金强调和极淡鼠尾草绿辅助色。
- 不使用小红书红作为大面积品牌色，只允许原始截图中自然出现。
- 卡片不使用厚重阴影；通过留白、边框、图片比例和排版层级建立质感。
- 标题字号克制，避免再次出现用户不喜欢的过大中文标题。
- 互动数据使用清晰的数字与中文标签，不使用平台图标堆叠。
- 图片统一采用圆角裁切，防止不同原图比例导致版面凌乱。

## 图片与资产处理

- 作品图片下载到 `public/hupai/`，不在生产页面热链小红书 CDN。
- 图片文件使用可读名称，并生成适合网页的 WebP 或 AVIF 版本。
- 保留足以辨认作品的分辨率，同时控制文件体积。
- 为每张图片提供描述内容和作品类型的 `alt` 文本。
- 原始截图仅作为作品证据，不替代网站自己的排版文字。
- 不抓取或保存评论区用户头像、昵称等与作品证明无关的个人信息。

## 交互

- 作品卡整体可点击，并提供明确的“查看原笔记”文本。
- 键盘焦点状态沿用现有按钮和链接体系。
- 悬停只做轻微图片缩放或边框变化，不增加夸张位移。
- `prefers-reduced-motion: reduce` 下取消图片缩放与进入动画。
- 不增加轮播、弹窗或横向拖动，避免与现有 3D 工牌争夺注意力。

## 响应式

### 桌面端

- 账号证据条横向排布；
- 作品区使用主次不对称三列；
- 图片与文字比例优先保证作品封面可读。

### 平板端

- 账号数据允许换行；
- 主案例独占一行，两个次案例并排。

### 手机端

- 账号证据条变为两列数据网格；
- 三张作品卡单列；
- 互动数据换行但不缩小到难以阅读；
- 原始截图裁切保持标题和数据可见；
- 链接触控区域不小于 44px。

## 可访问性与性能

- 所有链接有可理解的名称，不只依靠图片。
- 互动数据不只通过颜色区分。
- 原始截图提供替代文本；截图中的关键数字也必须以真实 HTML 文本重复呈现。
- 图片使用 `next/image` 或项目当前兼容的图片方案，设置明确宽高，避免布局偏移。
- 首屏之外图片启用延迟加载。
- 新增图片总传输体积以不显著拖慢手机端为目标，优先控制在约 1 MB 内。

## 验证标准

1. 虎派经历中能看到账号概览和三张代表作品。
2. 三张作品的标题、类型、互动数据与公开页面一致。
3. 所有数据都带有 2026-07-27 截取说明。
4. 点击作品可打开对应小红书原笔记。
5. 新增模块不展示手机号、评论区用户信息或其他新隐私信息。
6. 原有首页、能力雷达、工牌交互、简历下载和页脚邮箱不受影响。
7. 桌面、平板和手机端均无横向溢出。
8. 减弱动画模式下不运行新增视觉动效。
9. 生产构建与现有测试通过。

## 暂不包含

- 不新增小红书 API 或实时数据同步。
- 不展示无法从公开页面核实的后台数据。
- 不增加新的首页主标题或大面积视觉改版。
- 不修改虎派简历业绩数字。
- 不替换现有 3D 联系工牌或其交互。
