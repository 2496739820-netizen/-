# 庄澍凯个人作品集

面向高端眼镜门店新媒体运营岗位的个人作品集，重点展示虎派眼镜经历、运营能力、到店转化方法与可交互联系工牌。

## 技术栈

- Next.js 16
- React 19
- React Three Fiber
- Rapier 物理引擎

## 本地运行

```bash
pnpm install
pnpm dev
```

访问 `http://localhost:3000`。

## 验证

```bash
pnpm test
pnpm run build
```

## Vercel 部署

从 GitHub 导入仓库后使用以下设置：

- Framework Preset：Next.js
- Root Directory：`./`
- Build Command：保持默认
- Output Directory：保持默认
- Install Command：保持默认

项目不需要额外环境变量。标准生产构建会生成 Vercel 所需的 `.next` 目录。
